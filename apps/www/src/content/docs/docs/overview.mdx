**Simple Agent Manager (SAM)** is an open-source platform for getting real work done with AI coding agents. You create a project with a GitHub repository or, where enabled, a repository SAM hosts on the installation’s Cloudflare account, describe what you want in a chat, and SAM runs your choice of AI coding agent — Claude Code, OpenAI Codex, Gemini CLI, Google Antigravity, Mistral Vibe, OpenCode, or Amp — that can read your code, make changes, and open a pull request on GitHub when you ask. SAM provisions the environment for you.

## Why SAM?

AI coding agents need real development environments. SAM gives each agent an isolated environment behind a simple chat — a container that starts in seconds for conversation and focused edits, or a full cloud VM with your `.devcontainer`, Docker, and toolchain when the agent has to build and test your stack. You describe the outcome you want; SAM handles the servers and the setup. The agent commits, pushes, and opens pull requests when instructed.

## How It Works

1. **Sign in** via the web UI with GitHub, Google, GitLab or an emailed code
2. **Let SAM set you up**: on your first visit it asks where agents should work and where your code
   should live, connects your agent (Claude Code, Codex, Gemini CLI, and more), and creates your
   first project, on a GitHub repository or a new one SAM hosts for you
3. **Chat** — describe what you want; SAM provisions a workspace and runs the agent for you
4. **Get a pull request** — for a GitHub-backed project, ask the agent to open one when the work is ready (or say so in your first message), then review it on GitHub. SAM doesn't publish anything on its own.

## Key Features

- **Seven AI agents** — Claude Code, OpenAI Codex, Gemini CLI, Google Antigravity, Mistral Vibe, OpenCode, Amp
- **Chat-first UX** — describe what you want in plain language and watch the agent work in real time
- **Agent profiles** — save reusable agent + model + settings combinations and pick one per chat
- **Skills** — layer reusable instructions and tools on top of a profile for specific kinds of work
- **[Ideas](/docs/guides/ideas/)** — keep a list of work you want done; each idea follows the chats and pull requests that work on it, and shows what needs you
- **[Automation](/docs/guides/scheduled-actions/)** — start agent work on a schedule, from a GitHub event, a webhook or an email (preview), once at a time you pick, or as a multi-step workflow an agent planned, or ask an agent to set it up
- **[Use SAM from Claude and ChatGPT](/docs/guides/sam-connector/)** — check on your work, read whole replies, follow a team of agents, schedule work, start project chats, and answer your agents from the AI app you already use
- **[SAM assistant](/docs/guides/sam-assistant/)** (preview) — a private conversation inside SAM that checks your projects and starts or follows up on work
- **[Work as a team](/docs/guides/collaboration/)** — invite teammates to a project, comment on and @mention each other in any chat, and let a teammate drive your chat for up to an hour
- **File browsing in chat** — browse, view, and diff files without leaving the conversation
- **File upload & download** — attach files to conversations and download from workspaces
- **Conversation forking** — start a new session linked to this one, whose agent can read the original conversation, to explore an alternative
- **Voice input & TTS** — speak your prompts, listen to responses with a persistent audio player
- **Command palette** — quick navigation via Cmd+K / Ctrl+K
- **In-app notifications** — finished tasks, agent questions, mentions, comments, and progress updates
- **[App deployments](/docs/guides/app-deployments/)** — put your app on the internet: agents deploy it, and one page shows what's running, what went wrong, and the fix
- **Bring your own cloud** — run on your own Hetzner, Scaleway, Vultr, Infomaniak, DigitalOcean, UpCloud, or GCP account, or use compute credentials shared by your installation administrator
