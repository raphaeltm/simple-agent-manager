What access am I granting?

Our installer temporarily receives account read and Worker deployment permissions. These may allow changes to existing Workers in the selected account, not only SAM resources. You approve access on Cloudflare before continuing.

Full installation also requests account-token provisioning and access to the Cloudflare services SAM uses. It creates separate deployment, runtime and storage credentials in your account. These permissions can affect existing resources; review Cloudflare’s consent screen carefully.
