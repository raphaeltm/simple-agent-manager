Prefer to handle Cloudflare access yourself? Deploy this same open-source installer in your own account.

1. Get the source

You’ll need Node.js 22+, pnpm 9.15.9, a Workers Paid account, and an active domain in Cloudflare. Inspect the deployed source → 

git clone https://github.com/raphaeltm/simple-agent-manager.git
cd simple-agent-manager
# For an unmerged preview, check out the revision linked above.
pnpm install --frozen-lockfile

2. Configure your deployment

Set CLOUDFLARE_API_TOKEN and CLOUDFLARE_ACCOUNT_ID through your shell’s secret manager. Never commit credentials or paste them into chat.

The deployment token needs Account Settings Read, Workers Scripts Edit, OAuth Client Read/Write, and zone permissions for Workers Custom Domains and Workers Routes. Scope it to the account and zone you intend to use. 

export BASE_DOMAIN=example.com
pnpm --filter @simple-agent-manager/installer run deploy

3. Open your installer

The script deploys at https://install.example.com, registers a private OAuth client, and saves its credentials as Worker secrets. Keep those credentials private. Rerunning preserves the existing client and secret.

While this prototype is unmerged, check out the revision shown by “Inspect the deployed source” before deploying. The default branch may not include the installer yet.

Before sharing it with others

Private OAuth clients work for members of their parent account. Serving other users requires Cloudflare’s publisher verification and public promotion. Promotion is permanent and is never performed automatically by this script.

What you’re deploying

This is the installer prototype, separate from SAM. It creates a protected installation service and verifies ownership handoff. Full SAM installation, builds and updates aren’t connected yet.
