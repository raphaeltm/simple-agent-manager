# Complete AI SDK 7 dependency PR #2343

## Problem
Dependabot's `ai` 7.0.137 bump caused API type errors and blocked Type Check, Test, Build, all three Durable Object Workers shards, and their aggregate.

## Findings
AI SDK 7 resolves `@ai-sdk/provider` 4. `workers-ai-provider` 3.1.11 expects provider 3 and AI SDK 6. Mastra 1.9.0 does not accept provider 4 models. The seven failures all originated in TTS model construction. Existing TTS tests mock Mastra and the provider, so staging runtime verification was needed.
