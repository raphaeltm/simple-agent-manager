# Upgrade OpenCode to v2

Upgrade all SAM OpenCode runtimes from npm 1.18.32 to the latest stable v2 GitHub release with pinned SHA-256 checks. Ship through CI, real staging session/recovery, merge, and production deployment.

## Preflight and research

Classes: external-api-change, cross-component-change, infra-change, docs-sync-change.

Official source: anomalyco/opencode v2.2.5 (2026-10-30), latest stable v2 in release list; npm remains v1. GitHub /releases/latest still returns v1, so select stable v2 explicitly. v2.0.0 is a source tag without a published GitHub release; use the v2 migration guide in v2.2.5 services/www/src/docs/content/migrate-v1.mdx for breaking changes.

Data flow: shared agents.ts launches opencode acp → gateway.go installs/validates binary → session_host_startup.go injects OPENCODE_CONFIG_CONTENT and credential env → ACP private server handles JSON-RPC → XDG_DATA_HOME/opencode persists SQLite state → server session snapshots archive/restore state before LoadSession.

Direct binary probe (verified release SHA-256): initialize, session/new, session/load, session/set_config_option(model), session/set_mode pass; Go/glm-5.2 is visible when OPENCODE_API_KEY is set. ACP owns a private child server rather than attaching to shared background service. v2 normalizes V1 config and maps @ai-sdk/openai-compatible to bundled native provider; old npm cache preinstallation should be removed after prompt verification. Existing snapshot roots include the data directory and sidecars; verify v1 migration and v2 recovery rather than assuming compatibility.

Install manifest currently has only npm and uv-tool. Consumers: scripts/quality/check-agent-install-manifest.ts; cf-container Dockerfile and runtime contract tests. gateway.go and claude_version_test.go pin v1. No cloud-init install pin found.

Assumptions: Linux x64/arm64 devcontainers (glibc/musl), Instant Linux x64 glibc; installer must detect supported architectures and fail closed on unsupported systems. Pins/checksums are immutable reviewed release metadata. Preserve custom configuration behavior. Avoid secret-redaction and MCP tool-definition files.
